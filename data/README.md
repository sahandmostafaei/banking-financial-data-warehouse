# Data Directory

This directory contains the data used by the Banking Financial Data Warehouse project.

The project uses structured sample banking data representing:

- Customers
- Bank accounts
- Transactions
- Loans

The data is designed for educational and analytical purposes and does not contain real customer information.

## Data Model

The main relationships are:

- One customer can have multiple accounts.
- One account can have multiple transactions.
- One customer can have multiple loans.

These relationships allow the SQL analytics layer to perform customer-level, account-level, transaction-level, and loan-level analysis.

## Data Privacy

All records in this project are synthetic and are not associated with real individuals, financial institutions, or customer accounts.
